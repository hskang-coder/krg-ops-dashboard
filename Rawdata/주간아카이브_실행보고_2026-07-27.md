## 3. 조회 조건 입력 코드 수정 (해결됨)

- 날짜 입력 XPath `//input[@placeholder*="시작"]` 은 **문법적으로 잘못된 XPath**였습니다
  (`@placeholder*=`는 XPath에 없는 문법). → `//input[@placeholder="검색 시작일"]`로 교체
- Nuxt/Vue 바인딩 때문에 `send_keys`로는 값이 반영되지 않아 JS setter + `input`/`change` 이벤트 방식으로 변경
- 종료일이 항상 `-31`로 하드코딩되어 있던 문제 → `calendar.monthrange`로 월말 자동 계산
- 검색 버튼 → `button.last-btn2`

조회 조건 `2026-01-01 ~ 2026-03-31` 설정 및 검색 실행까지 **정상 동작 확인**했습니다.

## 4. 남은 문제 — 엑셀 다운로드 단계 (미해결)

`정보 다운로드` 버튼이 곧바로 파일을 받지 않고 **항목 선택 패널**(전체선택 / 전체해제 / 취소 / 완료)을 띄웁니다.
이 패널을 처리하도록 코드를 추가했으나, `완료` 클릭 후 파일이 생성되지 않고
**약 3~9분 뒤 Chrome이 스스로 종료**됩니다.

```
✗ 다운로드 실패 (2026-01 ~ 2026-03): InvalidSessionIdException
  invalid session id: session deleted as the browser has closed the connection
```

시도했으나 해결되지 않은 조치:

- 구 `--headless` → `--headless=new` 전환 (구 headless는 파일 다운로드를 차단함)
- CDP `Page.setDownloadBehavior` / `Browser.setDownloadBehavior`로 다운로드 경로 명시 허용
- 렌더러 메모리 완화 (`--max-old-space-size=4096`, 이미지 로딩 차단, 확장 비활성화)
- 전체 컬럼 선택(`전체선택`) 생략하고 기본 컬럼으로 내려받기 시도

3개월 × 약 1,900호실 규모라 서버 측 엑셀 생성이 오래 걸리거나,
headless 환경에서 렌더러가 버티지 못하는 것으로 추정됩니다.
